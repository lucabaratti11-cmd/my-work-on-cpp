# Coursework and Exercises

This directory contains C++ coursework and numbered programming exercises. The files are part of the learning materials in this repository; most `.cpp` files are standalone examples and should be compiled individually.

From the repository root, an exercise can be compiled with GCC as follows:

```bash
g++ -std=c++17 -Wall -Wextra "compiti c++/esercizio1.cpp" -o esercizio1
./esercizio1
```

For an overview of the repository, compiler requirements, Visual Studio Code setup, and license terms, see the [main README](../README.md).
