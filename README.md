# My Work on C++

Benvenuti in questo repository! Qui raccolgo i miei compiti, gli esercizi di programmazione e alcuni progetti personali sviluppati in **C++**.

Il repository è pubblico per permettere ai miei amici di consultare il codice facilmente senza bisogno di inviti.

## Organizzazione dei File

* **Esercizi e Compiti (`1.cpp`, `2.cpp`, `3.cpp`, ...):** Numerati in ordine consecutivo seguendo l'avanzamento dello studio.
* **Progetti Personali (`nome_funzione.cpp`):** File nominati in base al loro scopo o alla funzione specifica che svolgono.

## Come compilare ed eseguire

Il codice è scritto e testato utilizzando **Visual Studio Code** con il compilatore standard C++ integrato (**g++** / **MSVC** / **Clang**).

### Con Visual Studio Code
1. Scarica o clona il repository sul tuo computer.
2. Apri la cartella del progetto in **VS Code**.
3. Apri il file `.cpp` che ti interessa e clicca sull'icona **Play (Run C/C++ File)** in alto a destra.

### Da Terminale (alternativa rapida)
1. Clona il repository:
   ```bash
   git clone https://github.com/lucabaratti11-cmd/my-work-on-cpp.git
   ```
2. Compila ed esegui il file scelto:
   ```bash
   g++ 1.cpp -o programma
   ./programma
   ```
